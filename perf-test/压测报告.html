口径说明（面试可追问）

· A 组不是"把缓存关掉"，而是用 700 万个取值空间的随机 ID 让每个请求都是全新的 key，因此空值缓存和详情缓存必然全部 miss，效果等价于"没有缓存防护"。
· B 组与 A 组请求语义一致（都是查询不存在的商品），差别只在 ID 是否复用，所以两组可直接对比。
· C 组是正常业务路径（查存在的商品，缓存已预热）。
· A/B 组响应码为 400（商品不存在，业务预期响应，非系统错误）；三组均无 5xx、无超时。
· 单机压测，压测机与被压服务同机，QPS 绝对值仅用于横向对比，不代表生产容量。
