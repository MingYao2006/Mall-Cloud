# 网关认证测试说明

## 一、启动顺序

1. **启动 Nacos**（配置中心和服务注册中心）
2. **启动各微服务**（用户服务、订单服务等）
3. **启动 mall-gateway**（网关服务，端口 9000）

## 二、生成测试 Token

### 方法1：运行工具类主方法
```bash
# 在 IDE 中运行 JwtTokenUtil 的 main 方法
# 或使用 Maven 命令
cd mall-gateway
mvn exec:java -Dexec.mainClass="com.mall.gateway.util.JwtTokenUtil"
```

运行后会自动生成测试 Token 并输出测试命令。

### 方法2：在代码中调用
```java
String token = JwtTokenUtil.generateToken("1001", "testuser");
```

## 三、测试场景

### 场景1：不带 Token 访问（应返回 401）
```bash
curl http://localhost:9000/api/users/test
```

**预期结果**：返回 401 Unauthorized

### 场景2：带有效 Token 访问（应返回 200）
```bash
# 替换 YOUR_TOKEN 为实际生成的 Token
curl -H "Authorization: Bearer YOUR_TOKEN" http://localhost:9000/api/users/test
```

**预期结果**：返回 200 OK，并返回用户信息

### 场景3：带无效 Token 访问（应返回 401）
```bash
curl -H "Authorization: Bearer invalid_token" http://localhost:9000/api/users/test
```

**预期结果**：返回 401 Unauthorized

## 四、Postman 测试

### 请求配置
- **Method**: GET
- **URL**: `http://localhost:9000/api/users/test`
- **Headers**: 
  - Key: `Authorization`
  - Value: `Bearer YOUR_TOKEN`

### 测试步骤
1. 先不带 Authorization 头发送请求，验证返回 401
2. 添加有效的 Authorization 头，验证返回 200
3. 查看响应头中的 `X-User-Id` 和 `X-Username`（网关会传递这些信息）

## 五、白名单接口测试

以下接口不需要 Token 验证：

```bash
# 登录接口
curl -X POST http://localhost:9000/api/users/login

# 注册接口
curl -X POST http://localhost:9000/api/users/register

# 验证码接口
curl http://localhost:9000/api/users/code

# 支付回调接口
curl http://localhost:9000/api/pay/notify
```

**预期结果**：这些接口应该直接放行，不进行 Token 验证

## 六、常见问题

### 问题1：Token 验证失败
- 检查 `JwtTokenUtil` 中的 SECRET 是否与 `AuthGlobalFilter` 中的一致
- 检查 Token 是否过期（默认 24 小时有效期）
- 检查 Token 格式是否正确（需要 `Bearer ` 前缀）

### 问题2：返回 404
- 检查网关路由配置是否正确
- 检查目标微服务是否已启动并注册到 Nacos
- 检查请求路径是否正确

### 问题3：返回 500
- 检查网关日志，查看具体错误信息
- 检查 Nacos 配置是否正确
- 检查各微服务是否正常运行

## 七、验证用户信息传递

网关验证成功后，会将用户信息添加到请求头中传递给下游服务：
- `X-User-Id`: 用户ID
- `X-Username`: 用户名

下游服务可以通过以下方式获取：
```java
@GetMapping("/test")
public String test(@RequestHeader("X-User-Id") String userId,
                   @RequestHeader("X-Username") String username) {
    return "用户ID: " + userId + ", 用户名: " + username;
}
```

## 八、注意事项

1. **密钥安全**：生产环境中，SECRET 应该使用配置中心管理，不要硬编码在代码中
2. **Token 有效期**：根据业务需求调整 Token 有效期
3. **HTTPS**：生产环境必须使用 HTTPS，防止 Token 被窃取
4. **白名单配置**：根据实际业务需求调整白名单接口列表
