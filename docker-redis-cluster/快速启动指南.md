# Redis 集群快速启动指南

## 快速启动（3 步）

```powershell
# 1. 切换到项目目录
cd "D:\Java\project One\docker-redis-cluster"

# 2. 启动集群
docker-compose up -d

# 3. 查看容器状态
docker-compose ps
```

## 集群架构

- **redis-master**：主节点，端口 6379
- **redis-slave-1**：从节点1，端口 6380
- **redis-slave-2**：从节点2，端口 6381

## 常用命令

### 集群管理

```powershell
# 启动集群
docker-compose up -d

# 停止集群
docker-compose down

# 重启集群
docker-compose restart

# 查看容器状态
docker-compose ps

# 查看日志
docker-compose logs -f

# 查看单个容器日志
docker logs redis-master
docker logs redis-slave-1
docker logs redis-slave-2
```

### Redis 操作

```powershell
# 进入主节点 Redis CLI
docker exec -it redis-master redis-cli

# 进入从节点 Redis CLI
docker exec -it redis-slave-1 redis-cli
docker exec -it redis-slave-2 redis-cli

# 查看主节点复制信息
docker exec redis-master redis-cli info replication

# 查看从节点复制信息
docker exec redis-slave-1 redis-cli info replication
docker exec redis-slave-2 redis-cli info replication
```

### 数据操作测试

```powershell
# 在主节点写入数据
docker exec redis-master redis-cli set test_key "hello_redis"

# 从从节点读取数据（验证主从同步）
docker exec redis-slave-1 redis-cli get test_key
docker exec redis-slave-2 redis-cli get test_key

# 删除测试数据
docker exec redis-master redis-cli del test_key
```

## 连接信息

### 应用程序连接

```properties
# 主节点（读写）
redis.master.host=localhost
redis.master.port=6379

# 从节点1（只读）
redis.slave1.host=localhost
redis.slave1.port=6380

# 从节点2（只读）
redis.slave2.host=localhost
redis.slave2.port=6381
```

### Spring Boot 配置示例

```yaml
spring:
  redis:
    host: localhost
    port: 6379
    # 或使用连接池
    lettuce:
      pool:
        max-active: 8
        max-idle: 8
        min-idle: 0
```

## 故障排查

### 容器无法启动

```powershell
# 查看容器日志
docker-compose logs

# 检查端口占用
netstat -ano | findstr "6379"
netstat -ano | findstr "6380"
netstat -ano | findstr "6381"

# 重新创建容器
docker-compose down
docker-compose up -d
```

### 主从同步失败

```powershell
# 检查主节点状态
docker exec redis-master redis-cli info replication

# 检查从节点状态
docker exec redis-slave-1 redis-cli info replication
docker exec redis-slave-2 redis-cli info replication

# 重启从节点
docker-compose restart redis-slave-1 redis-slave-2
```

### 数据持久化问题

```powershell
# 检查数据目录
ls ./redis-data/master
ls ./redis-data/slave-1
ls ./redis-data/slave-2

# 清空数据（谨慎操作）
docker-compose down
rm -r ./redis-data/*
docker-compose up -d
```

## 注意事项

1. **数据持久化**：数据保存在 `./redis-data/` 目录，重启不会丢失
2. **自动启动**：容器配置了 `restart: unless-stopped`，Docker 启动时会自动运行
3. **镜像加速**：已配置国内镜像源，下载速度快
4. **端口冲突**：确保 6379、6380、6381 端口未被占用
5. **防火墙**：如需远程访问，请开放相应端口

## 快速清理

```powershell
# 停止并删除容器（保留数据）
docker-compose down

# 停止并删除容器和数据卷（清空数据）
docker-compose down -v

# 删除所有数据（谨慎操作）
docker-compose down
rm -r ./redis-data/*
```

## 常见问题

**Q: 如何修改密码？**
A: 编辑 `redis-conf/master.conf` 和 `redis-conf/slave-*.conf`，添加 `requirepass your_password`，然后重启容器。

**Q: 如何查看 Redis 版本？**
A: `docker exec redis-master redis-cli info server | findstr redis_version`

**Q: 如何监控 Redis 内存使用？**
A: `docker exec redis-master redis-cli info memory`

**Q: 如何备份 Redis 数据？**
A: `docker exec redis-master redis-cli bgsave`，然后复制 `./redis-data/master/dump.rdb` 文件。
